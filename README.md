# CodeAlpha AI Chatbot

## Project Overview
An AI-powered, retrieval-based chatbot developed
using Python and Flask for the CodeAlpha Cloud
Computing Internship Task 4.

## Features
- Predefined pattern-based responses
- Cloud computing FAQs
- Flask backend
- Website chat interface
- Input validation
- Responsive CSS design

## Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript

## Run Locally

1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Start the application:

   python app.py

4. Open http://127.0.0.1:5000

## Project Structure

- app.py
- chatbot.py
- templates/index.html
- static/style.css
- requirements.txt

## Limitations
This version uses predefined patterns and responses.
It does not generate answers using a large language model.
